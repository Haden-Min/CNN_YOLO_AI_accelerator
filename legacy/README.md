# Legacy Prototype

This directory preserves the original project files from the first development
iteration.

The legacy tree contains early experiments for:

- convolution processing elements
- padding and row-buffer logic
- max-pooling
- fixed-point BatchNorm
- PYNQ-side image preprocessing
- MATLAB/Python reference exploration
- conference and study materials

These files are kept for reference only. New development should happen in the
top-level `rtl/`, `sw/`, `scripts/`, `models/`, `tests/`, and `docs/`
directories.
